Vibe Music Player

A static GitHub Pages placeholder for the extracted Vibe music player repository.

Next.js App

Project: Spotify-style music player with upload, search, and PWA support.

About this repo

This repository contains a Next.js application built with:

  • Next.js 16
  • React 19
  • Tailwind CSS 4
  • Prisma + SQLite
  • PWA manifest + service worker

Because the app uses server APIs and dynamic features, GitHub Pages hosts this static landing page only.

How to use

Visit the repository or clone it locally to run the full application:

  • GitHub repository
  • Run with a Node.js or Bun environment and install dependencies
  • Use npm run build or bun build for production

Deployed to GitHub Pages from the gh-pages branch.
